# Ресурсы и активы для презентации "Начала Евклида"

Эта папка содержит статические ресурсы для презентации: изображения, иконки, шрифты и другие медиафайлы.

## Структура папки

```
assets/
├── images/              # Изображения и графики
│   ├── euclid-portrait.png
│   ├── euclidean-constructions.png
│   └── platonic-solids.png
├── icons/               # Иконки и SVG-графика
│   ├── euclid-icon.svg
│   ├── geometry-icon.svg
│   └── math-icon.svg
├── fonts/               # Локальные шрифты (опционально)
│   ├── playfair-display.woff2
│   └── source-sans-pro.woff2
└── data/                # Данные для визуализаций
    ├── euclid-books.json
    └── theorems-data.json
```

## Описание ресурсов

### 1. Изображения

**euclid-portrait.png** (рекомендуемые размеры: 300×300px)
- Портрет Евклида или стилизованное изображение
- Формат: PNG с прозрачностью
- Использование: на слайде "Что такое 'Начала'?"

**euclidean-constructions.png** (рекомендуемые размеры: 600×400px)
- Иллюстрации геометрических построений
- Формат: PNG или SVG
- Использование: в разделах о построениях

**platonic-solids.png** (рекомендуемые размеры: 800×400px)
- Изображения пяти правильных многогранников
- Формат: PNG с прозрачностью
- Использование: на слайде "Платоновы тела"

### 2. Иконки

**euclid-icon.svg** (рекомендуемые размеры: 64×64px)
- Иконка для фавикона сайта
- Стилизованное изображение циркуля и линейки
- Цвет: #2c3e50 (основной цвет темы)

**geometry-icon.svg**
- Иконки геометрических фигур
- Можно использовать для оформления списков

### 3. Шрифты

Проект использует Google Fonts:
- **Playfair Display** для заголовков
- **Source Sans Pro** для основного текста

Локальные копии шрифтов можно разместить в папке `fonts/` для офлайн-доступа.

## Создание собственных ресурсов

### Требования к изображениям
- **Формат:** PNG для фотографий, SVG для графики
- **Разрешение:** минимум 72 DPI для веба
- **Цветовая схема:** соответствует палитре проекта
- **Размер:** оптимизировать для быстрой загрузки

### Палитра цветов проекта


## Оптимизация ресурсов

### Для изображений PNG/JPEG:
```bash
# Используйте ImageMagick для сжатия
magick input.jpg -resize 1200x800 -quality 85 output.jpg

# Или optipng для PNG
optipng -o7 image.png
```

### Для SVG:
- Удалите лишние метаданные
- Объедините одинаковые элементы
- Используйте SVGOMG для оптимизации

## Скрипты для работы с ресурсами

### Оптимизация всех изображений (требуется ImageMagick)
```bash
#!/bin/bash
# optimize-images.sh
for img in assets/images/*.png; do
    optipng -o7 "$img"
done

for img in assets/images/*.jpg; do
    magick "$img" -resize 1200x800 -quality 85 "${img%.jpg}_optimized.jpg"
done
```

### Проверка размеров файлов
```bash
#!/bin/bash
# check-sizes.sh
find assets/ -type f \( -name "*.png" -o -name "*.jpg" -o -name "*.svg" \) \
    -exec du -h {} \; | sort -hr
```

## Примечания для разработчиков

1. **Кэширование:** Ресурсы должны иметь правильные заголовки кэширования
2. **Lazy loading:** Крупные изображения загружайте лениво
3. **Responsive images:** Используйте тег `<picture>` для адаптивных изображений
4. **Доступность:** Добавляйте alt-текст для всех изображений
5. **Производительность:** Сжимайте ресурсы перед коммитом
