# Начала Евклида: Суть главных математических фактов

Интерактивная презентация по Евклидовой геометрии с визуализациями и формулами для публикации на GitHub Pages.

![Лицензия](https://img.shields.io/badge/Лицензия-MIT-green)
![Версия](https://img.shields.io/badge/Версия-1.0.0-orange)

## 📖 О проекте

Этот проект представляет собой современную интерактивную презентацию, посвященную фундаментальному труду древнегреческого математика Евклида — "Начала" (Στοιχεῖα). Презентация создана с использованием современных веб-технологий и оптимизирована для публикации на GitHub Pages.

### Ключевые особенности:
- **Интерактивные визуализации** геометрических теорем и построений
- **Динамические формулы** с поддержкой LaTeX через MathJax
- **Адаптивный дизайн** для всех устройств
- **Плавные анимации** и переходы между слайдами
- **Полная совместимость** с GitHub Pages

## 🚀 Быстрый старт

### Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/bladsvytro/MM_Doklad.git
cd MM_Doklad
```

2. Откройте `index.html` в браузере:
```bash
# Для Windows
start index.html

# Для macOS
open index.html

# Для Linux
xdg-open index.html
```

Или используйте локальный сервер:
```bash
# С Python
python -m http.server 8000

# С Node.js (если установлен)
npx serve .
```

## 🌐 Развертывание на GitHub Pages

### Автоматическое развертывание (рекомендуется)

Проект настроен для автоматического деплоя через GitHub Actions. При пуше в ветку `main` презентация автоматически публикуется на GitHub Pages.

### Ручное развертывание

1. Перейдите в настройки репозитория → Pages
2. В разделе "Source" выберите ветку `main` и папку `/ (root)`
3. Нажмите "Save"
4. Через несколько минут сайт будет доступен по адресу: `https://<username>.github.io/MM_Doklad/`

## 🎨 Кастомизация

### Изменение контента

Для редактирования содержания презентации откройте `index.html` и найдите соответствующие секции:

```html
<section>
    <h2>Заголовок слайда</h2>
    <p>Содержимое слайда</p>
</section>
```

### Изменение стилей

Все стили находятся в `css/styles.css`. Основные CSS-переменные для быстрой настройки:

```css
:root {
    --primary-color: #2c3e50;    /* Основной цвет */
    --secondary-color: #3498db;  /* Вторичный цвет */
    --accent-color: #e74c3c;     /* Акцентный цвет */
    --golden-ratio: #f39c12;     /* Цвет золотого сечения */
}
```

### Добавление новых интерактивных элементов

Для добавления новых геометрических построений редактируйте `js/geometry.js`:

```javascript
class GeometryCanvas {
    // Добавьте новый метод
    drawNewConstruction() {
        // Ваш код здесь
    }
}
```

## 📚 Математические возможности

### Формулы LaTeX

В презентации поддерживается синтаксис LaTeX для формул:

- Встроенные формулы: `$E = mc^2$`
- Выделенные формулы: `$$ \int_a^b f(x)dx $$`
- Сложные выражения: `\[ \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} \]`

Доступные интерактивные построения:
